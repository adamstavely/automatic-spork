Help & Examples

Search Examples

Chinese Characters

Search using Chinese characters:

你好 中国

Pinyin

Search using Pinyin (with or without tone numbers):

ni3hao3 nihao zhongguo

Note: Use v instead of ü (e.g., nv for 女)

English

Search using English definitions:

hello restaurant China

Wildcards

Use * as a wildcard to match any characters:

  • rest* - matches words starting with "rest" (restaurant, restrain, etc.)
  • *文 - matches words ending with 文 (中文, 英文, etc.)
  • b*g - matches words starting with "b" and ending with "g"
  • *中国* - matches words containing 中国

Phrase Search

Use quotes for exact phrase matching:

"to rest"

This will only match entries where "to" and "rest" appear together.

Exclusion

Use - to exclude terms:

bill -gates

This will match entries with "bill" but exclude those with "gates".

Search Type Prefixes

Force search type with prefixes:

  • c:你好 - search Chinese only
  • p:ni3hao3 - search Pinyin only
  • e:hello - search English only

Features

Search

The main search page allows you to search the dictionary using Chinese characters, Pinyin, or English. Auto-complete suggestions appear as you type.

Handwriting Recognition

Draw Chinese characters on the canvas to recognize them. The system is tolerant of stroke order mistakes.

Text Annotation

Paste Chinese text and see word-by-word annotations. Three modes available: Chinese only, Chinese + Pinyin, or Chinese + Pinyin + English.

Character Details

Click on any character to see detailed information including stroke order animation, dictionary entries, and related information.

Radicals & Strokes

Browse Chinese radicals organized by stroke count. Click on a radical to find characters containing it.

Settings

Font Size

Toggle between Small and Large font sizes for Chinese characters. Your preference is saved automatically.

Simplified/Traditional

Switch between Simplified and Traditional Chinese character display. Your preference is saved automatically.

Keyboard Shortcuts

  • Enter - Submit search
  • Escape - Close popups
  • Arrow keys - Navigate suggestions (coming soon)
